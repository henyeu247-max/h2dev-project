# Bible Explainer V2.1 — pack nội bộ H2DEV

Nguồn gốc: thư mục `skill prompt - Bible Explainer` (bản nội bộ)

## Trong pack

| Thư mục / file | Dùng để |
|---|---|
| `skill prompt - Bible Explainer/script-bible-explainer.zip` | Skill viết kịch bản 6 phase (voiceover-ready) |
| `skill prompt - Bible Explainer/image-bible-explainer.zip` | Skill ảnh màu nước |
| `skill prompt - Bible Explainer/thumbnail-bible-explainer.zip` | Skill thumbnail |

| `skill prompt - Bible Explainer/thumb/` | 3 thumbnail mẫu |

## Cách dùng an toàn

- Copy **công thức**, **tự viết** nội dung. Không paste script đối thủ.
- Kết hợp pipeline `pipelines/ton-giao/` nếu cần tạo giọng đọc và ghép video.
- Ngách đăng: Bible / giải nghĩa tôn giáo EN — cần **wedge**, không làm bible stories generic.
