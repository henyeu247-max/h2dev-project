# CẨM NANG SỬ DỤNG — TOOL DỊCH PHỤ ĐỀ SRT VIP H2DEV (PHIÊN BẢN WEB)

## 1. Giới Thiệu Nền Tảng Tool Dịch H2DEV VIP
- **Địa chỉ truy cập**: trang web của tool (lời nói không nêu địa chỉ).
- **Đặc điểm nổi bật**:
  - Chạy trực tiếp trên nền tảng web: dùng được trên mọi hệ điều hành (kể cả macOS, mà bản desktop cũ không cài được) và dùng được cả trên điện thoại.
  - Không cần tải về, cài đặt hay giải nén file như bản desktop cũ.
  - Dùng **DeepSeek** để dịch, chất lượng mượt và chuẩn, tương đương hoặc hơn tool trước đó.
  - Không cần người dùng phải tự mua key API như các tool cũ (nhiều anh em không có thẻ Visa nên không mua được); tài khoản được tác giả cấp sẵn.

## 2. Tính Năng Chạy Ngầm Đa Tác Vụ (Background Multitasking)
- Điểm vượt trội nhất của phiên bản Web là khả năng **tiếp tục xử lý khi đã thoát khỏi web**:
  - Người dùng có thể chọn thêm file mới khi file trước đang chạy, tool chạy nhiều file cùng lúc (trong video demo có file hơn 30 phút và file dài hơn 1 tiếng).
  - Sau khi bấm **"Bắt đầu dịch"**, bạn có thể **tắt tab, thoát hẳn khỏi web** và làm việc khác.
  - Khi quay lại web và đăng nhập lại, file vẫn được xử lý và hoàn thành, khác với tool desktop chỉ import được một file và phải chờ chạy xong.

## 3. Chính Sách Các Gói Tài Khoản
1. **Gói Tháng (500.000 credit)**:
   - Tương đương khoảng 40 - 50 giờ dịch (tác giả ví dụ dịch được tầm 45 video dài 1 tiếng).
   - Cơ chế: Đúng 1 tháng hệ thống reset credit về 0, dù còn dư cũng vẫn reset; muốn dùng tiếp thì liên hệ tác giả để gia hạn.
2. **Gói Vĩnh Viễn (1 triệu 8 credit)**:
   - Dành cho người thích làm lâu dài.
   - Đăng nhập vĩnh viễn, không bị trừ credit theo tháng. Dùng hết thì liên hệ tác giả để nạp trực tiếp, không cần tự mua.

## 4. Quy Trình 4 Bước Dịch Phụ Đề & Xuất Bản
1. **Bước 1: Chuẩn bị file nguồn**:
   - Chuẩn bị file cần dịch (trong video demo là file phụ đề).
2. **Bước 2: Thiết lập dịch thuật trên Web**:
   - Sau khi mua gói trực tiếp với tác giả, bạn được cấp một key tài khoản; đăng nhập vào trang web của tool bằng key này.
   - Bấm **"Tạo mới"** → chọn file để dịch.
   - **Lưu ý quan trọng**: Chọn chính xác chiều dịch tại mục *Thiết lập dịch thuật* (ví dụ: `Trung Quốc sang Việt Nam`; còn có thể dịch sang Nhật Bản, tiếng Anh, Hàn Quốc...). Tác giả từng quên chọn nên file bị dịch từ Trung sang Trung.
3. **Bước 3: Theo dõi tiến độ thời gian thực**:
   - Thanh tiến trình hiển thị số phần trăm xử lý ngay ở danh sách.
   - Bấm vào biểu tượng **Con mắt (👁️)** để xem trực tiếp các dòng phụ đề đang được dịch ra theo thời gian thực.
4. **Bước 4: Kiểm tra và hoàn thiện**:
   - Khi file dịch xong sẽ hiện trạng thái hoàn thành, bấm **"Tải về"**.
   - Khuyến nghị: Mở file bằng **Notepad++** (tác giả hay dùng thay cho Notepad thường) để đọc và kiểm tra lại.
