# CẨM NANG SỬ DỤNG — TOOL DỊCH PHỤ ĐỀ SRT VIP H2DEV (PHIÊN BẢN WEB)

## 1. Giới Thiệu Nền Tảng Tool Dịch H2DEV VIP
- **Địa chỉ truy cập**: [https://h2devtool.com/](https://h2devtool.com/)
- **Đặc điểm nổi bật**:
  - Chạy trực tiếp 100% trên nền tảng Web: Tương thích hoàn hảo với **macOS, Windows, Linux, iPad, iPhone, Android**.
  - Không cần cài đặt phần mềm phức tạp, không cần giải nén file trên máy tính.
  - Tích hợp sẵn API **DeepSeek AI** cao cấp: Dịch thuật ngữ cảnh siêu mượt, văn phong tự nhiên thuần Việt, không bị dịch máy thô cứng.
  - Không cần người dùng phải tự mua thẻ Visa hay nạp key API riêng như các tool cũ.

## 2. Tính Năng Chạy Ngầm Đa Tác Vụ (Background Multitasking)
- Điểm vượt trội nhất của phiên bản Web là cơ chế **xử lý bất đồng bộ phía Server**:
  - Người dùng có thể tải lên nhiều file SRT cùng một lúc (hỗ trợ file dài từ 30 phút đến vài tiếng).
  - Sau khi bấm **"Bắt đầu dịch"**, bạn hoàn toàn có thể **tắt tab trình duyệt, tắt máy tính hoặc làm việc khác**.
  - Server H2DEV tiếp tục xử lý ngầm trên đám mây. Khi quay lại web và đăng nhập, file đã hoàn tất và sẵn sàng tải về.

## 3. Chính Sách Các Gói Tài Khoản
1. **Gói Tháng (500.000 Credits)**:
   - Tương đương khoảng 40 - 50 giờ thời lượng dịch phụ đề (dịch được ~45 - 50 video dài 1 tiếng).
   - Cơ chế: Hệ thống sẽ tự động reset số dư credit về 0 vào đúng chu kỳ 30 ngày.
2. **Gói Vĩnh Viễn (1.800.000 Credits)**:
   - Dành cho các studio và editor làm kênh lâu dài.
   - Không bị giới hạn thời gian sử dụng, không bị reset theo tháng. Dùng hết đến đâu nạp thêm đến đó qua Admin H2DEV.

## 4. Quy Trình 4 Bước Dịch Phụ Đề & Xuất Bản
1. **Bước 1: Chuẩn bị file nguồn**:
   - Sử dụng tính năng Download video đa nền tảng (Douyin, Kuaishou, Bilibili, TikTok, YouTube) có sẵn trên hệ thống.
   - Tách lấy file phụ đề gốc `.srt`.
2. **Bước 2: Thiết lập dịch thuật trên Web**:
   - Đăng nhập vào [h2devtool.com](https://h2devtool.com/) bằng Key được cấp.
   - Bấm **"Tạo mới"** → Tải file `.srt` lên.
   - **Lưu ý quan trọng**: Chọn chính xác chiều dịch tại mục *Thiết lập dịch thuật* (ví dụ: `Trung Quốc sang Việt Nam` hoặc `Nhật Bản sang Việt Nam`). Tránh chọn ngược chiều làm dịch sai ngôn ngữ.
3. **Bước 3: Theo dõi tiến độ thời gian thực**:
   - Thanh tiến trình hiển thị % xử lý.
   - Bấm vào biểu tượng **Con mắt (👁️)** để xem trực tiếp các dòng phụ đề đang được dịch ra theo thời gian thực.
4. **Bước 4: Kiểm tra và hoàn thiện**:
   - Bấm **"Tải về"** file phụ đề `.srt` đã hoàn thành.
   - Khuyến nghị: Mở kiểm tra bằng phần mềm **Notepad++** để soát lại đại từ nhân xưng và các thuật ngữ chuyên ngành trước khi đưa vào CapCut/Premiere dựng video.
