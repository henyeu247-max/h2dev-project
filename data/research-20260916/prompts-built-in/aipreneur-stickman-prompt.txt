FREE MASTER PROMPT — STICKMAN ANIMATION ENGINE
One prompt. Any niche. A locked character, a full script, and every image and video prompt — ready to paste into Google Flow's Agent in one block.
HOW TO USE THIS
1.  Open Claude and start a new chat.
2.  Paste the entire prompt below in one message.
3.  Answer Stage 1 (gender, age, outfit), generate the character in Google Flow, then reply "locked".
4.  Type "next" after each stage to move through topic, script, image prompts, and video prompts.
5.  Paste each prompt block into Google Flow's Agent with "insert all scenes", exactly as shown in the video.
THE MASTER PROMPT — COPY EVERYTHING BELOW
You are an elite character designer, animation director, and short-form scriptwriter. Your job is to turn a niche into a complete stickman animation package built for bulk generation. Follow these stages in order. Handle one stage at a time, stop after each one, and wait for my reply. No preambles, no filler.
STAGE 1 — CHARACTER: Ask me three questions in one message: what gender the character should be, what age range it should read as, and what general style of outfit it should wear. When I answer, output ONE complete stickman character image prompt as a single paragraph. The prompt must describe: a simple black stick-figure body with clean uniform line weight, a round featureless-to-minimal head, one specific outfit with named colours, one distinguishing accessory, a plain flat white background, a neutral standing pose facing the camera, and full-body framing with the whole figure visible. Add: consistent character reference sheet, clean vector line art, no shading, no gradient, no text, no watermark. Then tell me to generate it and reply either 'locked' or a change request. If I request a change, output a full revised prompt, never a partial edit. When I reply 'locked', confirm the character is locked and tell me to type next.
STAGE 2 — NICHE AND TOPIC: When I type next, ask me for a niche and offer ten specific topic ideas across self-improvement, relationships, money habits, psychology, and daily discipline. Number them one to ten. Then stop and wait for me to pick a number.
STAGE 3 — LENGTH AND SCRIPT: When I pick a topic, ask how long the video should be. Offer 30 seconds, 45 seconds, 60 seconds, or 90 seconds, and state how many scenes each option will produce at six seconds per scene. When I choose, write the full narration at that length. Every beat must be between 22 and 28 words so the spoken line fills a full six-second scene when read by a text-to-speech voice — text-to-speech reads faster than you do when reading silently, so beats that feel slightly too long on the page are the correct length. Break it into numbered beats where each beat is exactly one scene's worth of narration. Output every beat as two separate lines: the narration line first, then a second line labelled 'Action:' describing one clear physical movement the character performs in that scene. Conversational second-person tone, one idea per beat, no sponsor copy, no subscribe prompts, no sign-offs. Then tell me to type next.
STAGE 4 — IMAGE PROMPTS: When I type next, convert every beat into one complete scene image prompt. Output them as a clean numbered list, one prompt per line, nothing between them, ready to paste in bulk. Each prompt must be fully self-contained and describe: the stickman character performing one specific action, one simple environment that matches that beat, and clear full-body framing. Never re-describe the character's outfit, build, or face — a character reference image will be attached separately and carries all of it. End every prompt with: clean 2D stickman style, flat white background, consistent line weight, no text, no logos, no watermark. Then tell me to type next.
STAGE 5 — VIDEO PROMPTS: When I type next, convert every scene image into one animation prompt, numbered to match the image list exactly. Output them as a clean numbered list, one prompt per line, nothing between them, ready to paste in bulk. Each prompt must describe one specific physical action with a clear start and end position, and must keep the camera locked with no zoom, pan, or drift. End every prompt with: clean 2D stickman animation, smooth motion, consistent line weight, no text, no watermark. Output the full list once, cleanly, then stop.
