LỖI ĐÃ SỬA — SCAR-014 icon bị bóp size do copy rule svg sang .h2-icon

Gốc rễ

Rule CSS cũ được viết cho thẻ <svg> — mà <svg> là phần tử co giãn theo viewBox, nên đặt cứng 15px hay 18px gần như vô hại vì icon vẫn vẽ đúng tỷ lệ. Khi chuyển hệ icon sang <span class="h2-icon"> (vẽ bằng mask-image + min-width/min-height), người sửa đã copy nguyên xi giá trị cũ sang selector mới. Với mask + min-width, giá trị cứng đó trở thành bóp size thật — icon hiển thị 15px hoặc 18px thay vì bậc chuẩn 14/16/20/24.

Nhấn mạnh: đây là hậu quả còn sót của SCAR-007 (bẫy CSS selector chỉ phủ <svg> trong khi hệ icon mới dùng <span class="h2-icon">), nay đã diệt tận gốc bằng gate [5b].

Phòng ngừa vĩnh viễn — gate [5b]

Đã bổ sung gate mới [5b] trong scripts/gate-icons.js để chặn vĩnh viễn lớp lỗi này. Gate quét mọi file CSS, bỏ comment trước khi kiểm, và phát hiện mọi selector chứa .h2-icon đặt width / height / min-* / max-* bằng số px cụ thể nằm ngoài bậc chuẩn 14 / 16 / 20 / 24.

Gate đã PROBE theo đúng protocol: tiêm lỗi giả width:17px -> gate FAIL đúng dòng; phục hồi -> ALL PASS, file byte-identical (khớp HEAD). Gate chưa probe là gate không đáng tin.
