## Nguyên tắc cốt lõi xuyên suốt

1. **Tool chỉ là công cụ — kiến thức YouTube mới là sức mạnh.**
2. **Phong cách quyết định khả năng kiếm tiền:** Phim tài liệu chân thực > Drama/Hoạt hình/Xuyên không.
3. **Tách kênh khỏi môi trường mạng nhà** (proxy IPv4, trình duyệt riêng).
4. **AVD tăng bằng cách ghép đuôi video**, không tăng thời lượng video.
5. **Playlist đặt tên theo kênh đối thủ** — mẹo ăn đề xuất.
6. **Tạo gà AdSense trước khi bật kiếm tiền.**
7. **"Đúng, đủ, đều"** — đúng nội dung, đủ số lượng, đều đặn.
8. **KHÔNG mua khóa học đắt tiền** — tích lũy kinh nghiệm thực chiến.
