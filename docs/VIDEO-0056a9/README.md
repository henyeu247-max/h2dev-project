- ⚠ Không giữ nguyên trạng thái đang chọn layer video trên `CapCut Mobile` khi đi tìm nút `'Tỷ lệ khung hình'` hoặc `'Nền (Blur)'`, vì `CapCut` trên điện thoại chỉ hiện 2 nút này khi chạm ra vùng trống ngoài timeline.
